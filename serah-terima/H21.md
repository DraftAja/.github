## Kenapa serah terima ini ada

Kriteria rilis MVP butir 1 mewajibkan seluruh rangkaian tes lulus di SQLite dan sudah dijalankan sekali di PostgreSQL 16 dengan hasil tercatat. PM tidak bisa memutuskan rilis tanpa bukti ini, karena produksi memakai PostgreSQL di Azure sedangkan tes harian memakai SQLite.

## Isi paket

Bagian baru di doc 10 API, tabel Verifikasi:

| Baris | Isi |
|---|---|
| Rangkaian tes di PostgreSQL 16 | Commit, tanggal, jumlah lolos, dilewati, gagal. Target: nol error dan nol failure. |
| Tes konkurensi | `AcceptDocumentPostgresConcurrencyTest` dan `PatternLearnerPostgresConcurrencyTest` lulus |
| Migrasi dari kosong | `php artisan migrate` pada database kosong selesai tanpa error |
| Upgrade dari data | `migrate` pada salinan data dari [H15](H15.md) selesai; jumlah baris tabel utama sebelum dan sesudah sama |
| Schema check | Keluaran `php artisan documents:schema-check` sesudah upgrade |
| Pemulihan | Backup dipulihkan ke instance kosong dan aplikasi bisa membaca dokumen |
| Job CI | `continue-on-error` dihapus dari langkah PHPUnit PostgreSQL, sehingga kegagalan berikutnya memerahkan CI |
