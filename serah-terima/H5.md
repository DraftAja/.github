## Kenapa serah terima ini ada

WEB-1 membuat antarmuka tahan terhadap perubahan API yang belum terjadi: status dokumen baru, kode error baru, zona waktu server. Kasus seperti itu tidak muncul saat pemakaian biasa, jadi QA perlu cara memicunya dengan sengaja.

## Isi paket

| Butir | Yang diuji QA | Cara memicu |
|---|---|---|
| FE-01 status bawaan | Status yang belum dikenal tampil sebagai "Status tidak dikenal", halaman tidak rusak | Ubah `status` satu dokumen menjadi `in_review` lewat `php artisan tinker` |
| FE-02 mode baca | Dokumen selain draf terbuka tanpa tombol sunting | Dokumen yang sama dengan FE-01 |
| FE-04 jenis dokumen | Tidak ada pilihan Makalah, Skripsi, Laporan Praktikum, atau Studi Kasus di form | Buka `/dokumen/baru` dan dialog "Gunakan pola template" |
| FE-05 batas waktu polling | Pesan "Proses ini lebih lama dari biasanya." muncul | Hentikan `queue:work`, unggah template, tunggu 5 menit |
| FE-06 zona waktu | Dokumen yang diubah pukul 01.30 WIB tampil dengan tanggal WIB, sama di render server dan browser | Ubah `updated_at` menjadi `2026-11-03T18:30:00Z` |
| FE-07 kontras border | Border input terlihat jelas | Periksa manual dan dengan alat kontras peramban |
| FE-16 pesan 400 | Tidak ada teks `SANCTUM_STATEFUL_DOMAINS` yang tampil ke pengguna | Jalankan web di port 3001 tanpa mengubah env API, lalu coba masuk |
