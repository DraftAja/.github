## Kenapa serah terima ini ada

Web saat ini menulis sepuluh tipe respons dengan tangan di `src/lib/api/types.ts` bagian "Kontrak manual", karena Scramble tidak bisa membaca respons yang dibangun dari array biasa. Tipe tulisan tangan tidak diperiksa terhadap API, jadi perubahan API baru ketahuan saat aplikasi dipakai. Serah terima ini memindahkan tipe inti ke `openapi.json` dan menambahkan skema error, supaya `tsc` langsung gagal bila API dan web tidak cocok.

## Isi paket

| Bagian di `openapi.json` | Menggantikan tipe manual |
|---|---|
| Skema `ErrorResponse` (`message`, `code`) dan `ValidationErrorResponse` (`message`, `errors`, `code`) dirujuk oleh semua respons 4xx dan 5xx | penanganan error yang menebak dari status |
| Respons `GET /dashboard` | `Dashboard` |
| Respons `GET /laporan/options` | `LaporanOptions` |
| `document_style` di `GET /laporan/{id}` | `DocumentStyle`, `LaporanDetail` |
| Respons `GET /templates`, termasuk `providers` | `TemplateIndex`, `ProviderReadiness` |
| Respons `GET /templates/{id}/analysis` | `TemplateAnalysis` |
| Respons `POST /templates` dan impor (202 dan 200) | `UploadReservation` |
| Respons `POST /templates/{id}/document` dan `/use` | `OpenedDocument` |
| `securitySchemes` cookie session dan header CSRF (BE-11) | tidak ada, sebelumnya kosong |

Bentuk JSON yang sudah ada tidak berubah. Yang berubah hanya dokumen kontraknya, ditambah field `code` pada error.
